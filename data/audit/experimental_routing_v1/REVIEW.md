# Historical routing and P7 review

This audit scopes 6000 membership cells across 60 cutoffs and 209 historical ticker codes. It changes no production behavior and does not classify all cells.

The existing M3 package is reproducible but its 208 ordinary ticker routes derive from the 2026-08-24 KAP sector snapshot. The remaining GRTHO ticker has two dated route intervals based on KAP 1331451. The sector-change archive audit is useful bounded evidence, not a historical six-family register. XUMAL must not be passed to the production default family router to infer FINANCIAL for every financial-sector company. A broad benchmark and an M2 engine family have different meanings.

For the new experiment, legal company names and specialized statement roles in a hash-bound dated report can support report-asof family inference. Exact Turkish-normalized GAYRIMENKUL YATIRIM ORTAKLIGI and HOLDING identify GYO and HOLDING, subject to conflicting evidence rejection. Generic statement roles do not establish NONFIN. Identity changes must use effective-dated ticker lineage, not arbitrary replacement with today's ticker. Publication visibility remains required even when the financial period is older.

A dated financial family does not independently establish XUMAL constituent membership. Explicitly choosing XUMAL as an experimental model benchmark would be a separate disclosed model policy, not source-confirmed historical routing. Without such a policy and evidence, reject M3 routing per cell while retaining any independently calculated CORE facts.

Database-free reuse path: parse_kap_bulk_export_report and parse_kap_bulk_financial_cells -> bulk_cells_to_financial_facts -> existing exact semantic mapper -> derive_company_quarters -> compute_company_core_ratios_from_frame -> HistoricalPitRatioReplayResult -> run_historical_pit_rsc_replay. The caller must preserve as-of selection before the pure CORE function; that function itself does not enforce publication cutoff. Quarter derivation retains missing prior-YTD reasons instead of filling missing flows. RSC uses the existing score_quarter mathematics and requires exact family routing and the same ticker set as the ratio foundation. CORE-only computation is not a claim of complete CORE+VAL readiness.

VAL remains separately gated by price publication/t0/cutoff and share-basis evidence. The existing _compute_val_ratios_for_row is pure arithmetic; bypassing source checks to call it does not certify VAL readiness. The public historical foundation currently accepts a DB connection, while the CORE and RSC inner paths are already pure. All six M2 replay adapters accept historical frames; missing required metrics and NAV/capital/action provenance should remain explicit cell/module rejections rather than a global catalog failure.

P7 cannot be upgraded from raw archive hashes: the preserved summary explicitly records incomplete historical version enumeration. Reconstructed metadata and timestamp-filtered visible reports permit the accepted-risk experimental path, but cannot prove a missing superseded original did not exist. Original and superseded IDs, publication times, ordering, and completeness provenance are still required.

The JSON receipt records code/source SHA256 and the full candidate ticker set. These are review findings and suggested experiment constraints, not a successful runtime materialization receipt.

Implementation clarification: the partial CORE helper permits explicit (economic, technical) pairs (HOLDING, HOLDING), (HOLDING, NONFIN), and (GYO, NONFIN). A dated legal holding/GYO can use the general statement schema without becoming an economic NONFIN company. Exact mapped facts and derived quarter family remain technical NONFIN; only the evidence-backed RSC policy route is HOLDING/GYO. Every contributing own report must support the same economic family. No default NONFIN, bank, insurance, or financial specialist route is inferred. NA ratios are removed before scoring and each ratio requires five present same-family peers, so absent inputs cannot become neutral scores.
